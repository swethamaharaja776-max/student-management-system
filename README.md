# 🎓 Student Management System

A simple, modern, and responsive **Student Management System** built using **HTML, CSS, and JavaScript**.

It helps manage student records efficiently with CRUD operations, search, filters, dashboard statistics, and local data storage.

## 🚀 Live Demo

https://swethamaharaja776-max.github.io/Student-management-system-/

## 📌 Features

* ➕ Add student records
* 👀 View student details
* ✏️ Edit student information
* 🗑️ Delete student records
* 🔍 Search students
* 🎯 Filter by department, year, and placement status
* 📊 Dashboard statistics
* 📈 Department-wise reports
* ⭐ CGPA calculation
* 💼 Placement status tracking
* 🌙 Dark mode
* 💾 LocalStorage data persistence
* 📱 Fully responsive design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* LocalStorage

## ⚙️ How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Start managing student records.

No backend or database setup is required.

## 💡 CRUD Operations

The application supports:

**Create** → Add new students
**Read** → View student records
**Update** → Edit existing records
**Delete** → Remove student records

## 💾 Data Storage

Student information is stored using the browser's **LocalStorage**, so the data remains available even after refreshing the page.
